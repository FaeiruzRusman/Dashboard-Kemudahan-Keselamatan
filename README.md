# Dashboard Kemudahan Keselamatan Negeri Selangor V3.6

## V3.6 — Facility Density Analysis
- Menambah tab baharu **Density Analysis**.
- Analisis boleh ditukar antara **Daerah** dan **PBT**.
- Filter mengikut **Semua Agensi, PDRM, JBPM atau APM**.
- Mengira jumlah kemudahan dalam setiap kawasan pentadbiran.
- Mengira **density kemudahan per 100 km²** berdasarkan keluasan kawasan.
- Papar choropleth map daripada density rendah hingga tinggi.
- Papar purata density, jumlah kawasan dianalisis, jumlah kemudahan dan kawasan tanpa kemudahan.
- Papar kawasan dengan density tertinggi.
- Papar ranking density dalam chart dan jadual.
- Tidak memerlukan API luar atau API key.

## V3.5 — Nearest Facility Fix
- Membetulkan pemilihan lokasi apabila klik peta dalam tab **Nearest Facility**.
- Menambah fallback click handler supaya klik pada layer/marker peta tetap boleh dijadikan lokasi analisis.
- Map menggunakan cursor crosshair apabila modul Nearest Facility aktif.
- Marker lokasi analisis dibuat lebih jelas.

> Nota: Density ialah indikator spatial berasaskan bilangan fasiliti dan keluasan kawasan. Ia belum mengambil kira populasi, waktu tindak balas atau rangkaian jalan.
